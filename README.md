# ?? PlanOS Navigator

> **Serverless Realtime Personal Operating System Web Dashboard**

## ?? 特點 (Features)

- **100% Serverless**: 純前端靜態網頁（HTML/CSS/JS），零伺服器維護負擔、零費用。
- **Direct GitHub API Integration**: 透過 GitHub REST API 直接讀寫私有庫（Private Repo）之 PIPELINE.md。
- **Zero Conflict (消滅雷霆衝突)**: 手機端 1-Tap 點擊打勾，自動於背景執行單行精準 Commit 回寫。
- **Privacy & Security First**: 金鑰 (Personal Access Token) **100% 僅儲存於使用者本機瀏覽器 (localStorage)**，絕無任何中間伺服器介入。
- **PWA & Mobile-First**: 支援 iOS/Android「加入主畫面」，享有原生 App 般的黑魂極致體驗。
